# REAL Funding Radar

Community dashboard for exploring REAL perpetual funding rates, historical payments, and estimated position costs.

## Planned MVP

- Rank markets by positive and negative funding
- Compare 1 day, 7 day, and 30 day history
- Estimate funding paid or received for a position size
- Work with REAL mainnet or testnet indexer endpoints

This project is community-built and is not affiliated with Real Markets.
